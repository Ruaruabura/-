## 未验证的外部条件

当前实例没有用户的 ChatGPT OAuth 凭证。真实浏览器登录、订阅资格、目标模型权益和额外收费设置未实测。自动化测试没有消费真实账号额度，也不能证明真实订阅可用。

用户在本机完成 `npm run login`，核对账号费用设置后运行 `npm run verify:pi -- --confirm-subscription`，实际通过才会启用执行。账号命令与服务使用同一实例锁，验证前应停止工作台。

## 实现选择

1. 使用现有云端隔离 checkout 的 `work` 分支，没有额外创建 worktree。
2. Pi 官方包迁移后固定使用 `@earendil-works/*` 1.3.0。使用 Agent 核心和 Models API，避免完整 coding-agent 自动发现工具或发起后台调用。公开 AuthStorage 已移除，改用公开 CredentialStore 接口与锁定、原子保存的 Pi 兼容认证文件。真实登录互通仍需账号实测。
3. 对话历史纳入同一 20,000 字符预算，长对话会暂停而非静默裁剪。
4. Playwright 下载域名被策略拦截，使用环境已有 Chromium 完成测试，未关闭 TLS 或绕过网络策略。
5. 云端技能资源在执行后期变为不可用，无法运行技能附带的辅助脚本或读取补充模板；继续按已读取的执行规程维护日志、实跑检查和安排独立审查。
